# Security policy

Please **do not** open public GitHub issues for security concerns.

## Reporting a vulnerability

Email: [dxrksvng@gmail.com](mailto:dxrksvng@gmail.com)

Please include:

- A description of the issue
- Steps to reproduce
- Your assessment of impact

You will receive an acknowledgement within **7 days**. If you do not, please
follow up — the email may not have arrived.

We do not currently run a bug bounty.

## Disclosure timeline

We ask for **90 days** from acknowledgement before public disclosure, to give us
time to investigate and patch. We may request a longer window for complex issues
and will explain why if so.
